# TikTok strategy
Use parent `../../SKILL.md` and shared references.

## Creative priorities
- Hook in opening 1–3s; fast context and reveal; test 15s vs 25–30s clips.
- Prioritize truthful curiosity, contrast, destination choices, comment prompts and serial storytelling.
- Produce on-screen overlay, Brazilian Portuguese voiceover or text-first variant, SEO-friendly caption using location names.
- Avoid obvious generic engagement bait and unsupported claims.
- For reach videos, ask a relevant question or for sharing; for planning videos, direct to the matching ExploraAI guide via the profile link *only if available*.

## Test and measurement
Test hook A/B first, then narration, pacing and CTA. Measure average watch time, completion, shares per 1k views, profile visits, new followers and attributed site sessions. Do not invent universal benchmark numbers or claim optimal posting hours without account data.

## Output
Return `templates/video-brief.md` filled as TikTok version, plus hypotheses and TikTok caption. Keep an independent TikTok video ID and tracking campaign.
