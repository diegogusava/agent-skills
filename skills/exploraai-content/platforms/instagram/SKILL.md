# Instagram strategy
Use parent `../../SKILL.md` and shared references.

## Creative priorities
- Reels: compelling opening image and legible cover headline; combine destination beauty with a clear useful takeaway.
- Consider companion carousel for itineraries, comparisons, checklists and accommodation-location advice.
- Stories: use link sticker if available and relevant; summarize guide, use appropriate interactive features and link to destination-specific page.
- Include clear saving/sharing motivation where truly useful; avoid generic engagement bait.
- Adapt opening, pacing, cover, text density and CTA separately from TikTok version. Do not cross-post videos with TikTok watermark.

## Test and measurement
Test Reels cover, format (Reel vs carousel for same topic), hook and CTA. Measure watch time where available, shares, saves, profile actions, link taps, attributed site sessions and quality of traffic. Account features vary; verify what is available.

## Output
Return `templates/video-brief.md` filled as Instagram version, cover concept, Reel caption, optional 5-slide carousel outline, Story follow-up concept and tracking campaign.
