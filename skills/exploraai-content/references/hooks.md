# Hook generator
Return three truthful variants per idea:
1. Curiosity gap: "Esse lugar fica no Brasil — consegue adivinhar onde?"
2. Useful payoff: "Antes de visitar [destino], confira estas 3 dicas."
3. Choice: "Você escolheria [A] ou [B] para suas férias?"

Hook rules: show strong, relevant visual immediately; make claim verifiable; put payoff within first few seconds; avoid misleading surprise. Test one variable at a time. Record which hook is used and how it performs.
