# Measurement and learning
Record for each platform, video, publication date and reporting window: views, unique viewers if available, average watch time, completion rate, shares, saves, comments, likes, followers gained, profile visits, link clicks, attributed site sessions, engaged sessions, lodging searches, partner clicks.

Derived metrics:
- shares per 1k views = shares / views * 1000
- follow conversion = follows / views * 100
- profile visit rate = profile visits / views * 100
- link CTR = link clicks / profile visits * 100 (only if attribution and denominators are valid)
- partner click rate = partner clicks / attributed site sessions * 100

Use GA4 UTMs where supported, for example:
https://www.exploraai.com.br/tiktok?utm_source=tiktok&utm_medium=organic_social&utm_campaign=br_beaches&utm_content=jeri_001
Ensure target URL exists. Avoid assuming TikTok or Instagram expose each metric for each account type. State unavailable metrics.

Experiments: compare similar topics and release windows, isolate hook/length/narration/CTA, use multiple matched videos and refrain from claiming causality from a single pair. Choose next batch using observed qualified traffic AND reach; high view count alone is not success.
