# Production standards
- Master footage: keep high-quality clean original, rights/licensing evidence and destination metadata.
- Deliverables by platform: 9:16, target 1080x1920, legible captions inside safe areas, clear first 1–3 seconds, no platform watermark.
- Typical length to test: 15–30 seconds; not an algorithm guarantee.
- Structure: hook -> location/value reveal -> useful payoff -> CTA.
- Music: rights cleared for actual account/business usage; keep voiceover audible.
- Travel accuracy: footage should match exact location; do not silently swap beaches/destinations. Verify access, fees, travel times and prices when mentioned.
- Approval before publish. If video-render tools are not available, output an exact editing timeline instead of pretending that an MP4 exists.
