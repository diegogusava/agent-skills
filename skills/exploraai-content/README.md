# ExploraAI social content skills for Grokbot

Three cooperating skills:
1. `SKILL.md`: shared ExploraAI video producer.
2. `platforms/tiktok/SKILL.md`: TikTok version.
3. `platforms/instagram/SKILL.md`: Instagram version.

## Installation
Upload/extract the complete directory into Grokbot's supported skills or project knowledge location. Skill support and paths depend on the Grokbot environment; if automatic skill loading is not supported, provide `SKILL.md` and reference files as persistent instructions and ask the agent to read platform-specific files when needed.

## Starter prompt
Use the ExploraAI producer skill plus both platform skills. Propose 7 Brazilian travel video concepts. For each, create 3 hooks, PT-BR scripts, TikTok and Instagram variants, a licensed footage asset shortlist, editing timeline, platform captions and a clear metric hypothesis. Present asset selections for my approval before paid downloads. Do not publish without my approval. After publication, analyze platform metrics and attributed traffic before proposing the next batch.

## Important
The files are agent instructions and templates, not executable code or guaranteed integrations with Grokbot, stock providers, editing tools or social APIs. Never bypass paid stock licensing or provider security restrictions.
